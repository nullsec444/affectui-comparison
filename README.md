# affectUI comparison

Side-by-side comparison of the paid affectUI public demos: the original published demo next to a replay rebuilt from JSX recovered with [REA](https://github.com/morluto/rea).

- Live site: https://nullsec444.github.io/affectui-comparison/
- Download the recovered JSX: [latest release](https://github.com/nullsec444/affectui-comparison/releases/latest)

Recovered code is `.jsx` reconstructed from public demo bundles. Original identifiers, TypeScript types, comments and file names are not recovered.
